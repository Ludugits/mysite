RetroAuto — Инструкция по запуску проекта (Лабораторная работа №6)
==================================================================

Проект содержит две реализации интернет-магазина RetroAuto:
1. Основная (современная): React + Vite + Bootstrap 5 (работает локально без MySQL)
2. Альтернативная (классическая): PHP + MySQL + Bootstrap 5


ВАРИАНТ 1: Запуск React-версии (Основной)
----------------------------------------
Данная версия полностью интерактивна (работает каталог, корзина, оформление заказов, 
страница «О себе», «Лабораторные» и «Обратная связь»). Ей не требуется сервер баз данных.

Шаги для запуска:
1. Установите NodeJS (если он еще не установлен) с официального сайта: https://nodejs.org/
2. Откройте терминал в папке проекта.
3. Установите зависимости (если запускаете впервые на другом ПК):
   npm install
4. Запустите сервер разработки:
   npm run dev
5. В консоли отобразится локальный адрес. Обычно это:
   http://localhost:5173/  или  http://localhost:5174/
   Откройте эту ссылку в браузере.

Для создания продакшн-сборки (папка dist):
   npm run build


ВАРИАНТ 2: Запуск PHP-версии (Альтернативный)
--------------------------------------------
Данная версия использует классический веб-сервер и реляционную базу данных MySQL.

Шаги для запуска:
1. Запустите локальный веб-сервер с поддержкой PHP и MySQL (например, OpenServer, XAMPP, MAMP или Laragon).
2. Скопируйте файлы проекта в корневую папку вашего сервера (например, htdocs в XAMPP или папка домена в OpenServer).
3. Убедитесь, что сервер MySQL запущен.
4. Выполните автоматическую установку базы данных и таблиц, перейдя по адресу:
   http://localhost/install.php
   (Замените localhost на имя вашего виртуального хоста, если необходимо).
   Вы увидите сообщение об успешном создании базы данных "retroauto".
5. Откройте главную страницу сайта:
   http://localhost/index.php
   
*Примечание: настройки подключения к БД находятся в файле partials/db.php.
